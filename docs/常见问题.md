# DirNetBlock 常见问题（FAQ）

## Q1：封禁之后程序还是能联网？

按顺序排查：

1. **防火墙被关闭**：本工具封禁前会自动开启 Windows 防火墙。但如果电脑上装了 360、腾讯管家等安全软件，它们可能接管/关闭了防火墙。请在安全软件中恢复 Windows 防火墙。
2. **规则确实存在但无效**：部分程序（如带驱动的、或由系统服务启动的）可能绕过应用层规则。内核驱动级联网（NDIS/TDI 驱动）不经过防火墙应用层匹配，这类情况需要更底层的拦截（如 WFP Callout 驱动），不属于本工具的适用范围。
3. **确认是目标程序自身在联网**：程序可能把请求委托给其他已联网进程（如系统服务、COM 组件）。

## Q2：杀毒软件报毒 / 提示有风险？

本工具需要管理员权限、操作防火墙规则、遍历进程，这些行为与远程控制类软件相似，容易被启发式引擎误报。

- 本项目**完全开源**，无任何恶意行为，**不联网、不上传数据**；
- 请核对源码后，在杀毒软件中把 `DirNetBlock.exe` 加入信任；
- 若使用预编译版本，可用源码自行编译，产物与 Release 一致。

## Q3：怎么解除某个目录的封禁？

- **GUI**：在顶部目录列表中选中该目录 → 点「解除选中目录」，一次性删除该目录全部规则；
- **CLI**：`DirNetBlock_cli.exe --unblock <目录>`。

## Q4：规则数量很多，会不会拖慢系统？

封禁规则由 Windows 防火墙引擎（BFE）维护，每条规则只按程序路径匹配，对系统性能影响极小。上千条规则在界面上查询时会有 1~2 秒延迟，属正常现象。

## Q5：开机自启后怎么关闭？

- GUI 取消勾选「开机自启」；
- 或托盘图标右键 → 取消「开机自启」；
- 或命令行 `DirNetBlock_cli.exe --autostart-off`。

## Q6：怎么彻底卸载？

1. 运行 GUI → 点「全部解除」（删除所有规则）；
2. 托盘菜单取消「开机自启」；
3. 删除程序目录和 `%APPDATA%\DirNetBlock` 即可（绿色软件，无安装痕迹）。

## Q7：支持 32 位系统吗？

支持。编译时若 64 位 csc 不可用会自动回退 32 位；系统工具封禁同时覆盖 System32 和 SysWOW64。

## Q8：能不能封禁单个文件而不是整个目录？

可以。GUI 中封禁目录后，在列表里选中单个程序 → 「解除选中」即可单独放行；需要单独封禁单文件时，把该文件所在目录加入后，再解除其他不需要的程序即可（或提 Issue 反馈）。

## Q9：程序和它拉起的子进程都会被封吗？

勾选「子进程自动封禁」后：运行目录中的程序，其拉起的子进程（包括跨层子孙进程）会被实时监控并自动加入封禁。排除项：`conhost.exe`（终端宿主）、`powershell.exe`（保留系统管理能力，建议通过配置自行决定）。
