# DirNetBlock 使用说明

## 一、图形界面（GUI）

以管理员身份运行 `DirNetBlock.exe`，界面分为：

### 1. 封禁目录区（顶部）
- **添加目录…**：选择要封禁的目录（可添加多个）
- **封禁联网**：对列表中的所有目录执行封禁（自动先开启防火墙）
- **解除选中**：解除程序列表中选中的程序
- **全部解除**：解除本工具添加的所有规则（含系统工具、子进程）
- **移除选中目录**：仅从管理列表移除目录（不删除已封禁规则）
- **解除选中目录**：选中目录后一次性解除该目录下全部规则并移除

### 2. 选项
- **同时封禁系统网络工具**：封禁 curl / certutil 等 17 个可被借刀联网的系统工具
- **子进程自动封禁**：目标目录程序拉起的子进程会被自动封禁
- **开机自启**：注册开机自动启动并恢复封禁状态

### 3. 封禁列表
按三个分组展示：
- **目录**（灰底）：每个目录下的程序及封禁状态
- **系统网络工具**（蓝底）：已封禁的系统工具
- **自动封禁的子进程**（红底）：运行目录程序后，其拉起的子进程实时显示

### 4. 托盘
点击窗口右上角 ✕ 会最小化到系统托盘（后台继续运行，子进程监视不中断）。右键托盘图标可「显示主界面」或「退出」。

## 二、命令行（CLI）

```
DirNetBlock_cli.exe --block <目录> [目录2 ...]
```
示例：
```
DirNetBlock_cli.exe --block D:\test
DirNetBlock_cli.exe --block "C:\Program Files (x86)\Microsoft\Edge" D:\test
DirNetBlock_cli.exe --block-hard D:\test
DirNetBlock_cli.exe --unblock D:\test
DirNetBlock_cli.exe --unblock-all
```

## 三、开机自启说明

- GUI 勾选「开机自启」即写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，注册的是 `DirNetBlock.exe --autostart`
- 自启后窗口隐藏、后台运行，自动恢复上次封禁的目录规则并开启子进程监视
- 取消勾选或托盘菜单取消即可关闭

## 四、配置文件

- 位置：`%APPDATA%\DirNetBlock\config.ini`
- 内容：封禁目录列表（`Dir=`）、系统工具开关（`SysTools=`）、子进程监视开关（`ChildGuard=`）、自动封禁子进程记录（`AutoBlocked=`）
- 删除该文件即恢复初始状态（不会删除防火墙规则，规则需用「全部解除」清理）
