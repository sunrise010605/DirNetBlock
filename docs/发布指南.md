# DirNetBlock 开源发布指南

本文件是发布到 GitHub 的完整操作清单（供仓库维护者使用，不随 Release 分发）。

## 一、发布前准备（代码侧）

1. **确认源码版权头**：建议在 `src/DirNetBlock.cs` 文件头部加一行 MIT 声明：
   ```
   // SPDX-License-Identifier: MIT
   // Copyright (c) 2026 DirNetBlock contributors
   ```
2. **确认无个人敏感信息**：检查源码/配置中是否有本机路径、用户名、测试残留（如 `D:\todesk` 等测试目录不应出现在代码中）。
3. **清理测试规则**：发布前确认开发机上无残留测试防火墙规则（可用 `--unblock-all` 清理）。

## 三、GitHub 操作步骤

### 方案 A：云端直接推送（推荐，用 gh CLI）

```bash
# 1. 登录 GitHub（弹浏览器授权）
gh auth login

# 2. 创建远程仓库（Public + MIT 已就绪）
cd DirNetBlock
gh repo create DirNetBlock --public --source . --remote origin --push

# 3. 首次提交
git add -A
git commit -m "feat: 目录级内核封网工具 DirNetBlock v1.0"
git push -u origin main
```

### 方案 B：网页手动创建

1. GitHub 网页 → New repository → 名称 `DirNetBlock` → Public → Create
2. 本地（任意机器）：
   ```bash
   git init
   git add -A
   git commit -m "init"
   git remote add origin https://github.com/<你的用户名>/DirNetBlock.git
   git branch -M main
   git push -u origin main
   ```

## 四、发布 Release（可选但推荐）

```bash
# 打标签
git tag v1.0.0
git push origin v1.0.0

# 在 Release 页面（或 gh release create）上传：
#   - bin/DirNetBlock.exe          （GUI 版，Windows 编译）
#   - bin/DirNetBlock_cli.exe      （CLI 版）
#   - 源码 zip（GitHub 自动生成）
```

Release 说明模板：

```
## DirNetBlock v1.0.0

### 功能
- 目录级批量封禁（出站+入站 Block 规则，内核 WFP/BFE 执行）
- 多目录管理 + 整目录一键解除
- 系统网络工具封禁（17 个）防“借刀”联网
- 子进程自动封禁（拉起即封）
- 开机自启 + 托盘后台运行
- GUI / CLI 双模式

### 下载
- DirNetBlock.exe（GUI，右键以管理员身份运行）
- DirNetBlock_cli.exe（命令行）

### 系统要求
Windows 7/10/11 + .NET Framework 4.0+ + 管理员权限
```

## 五、发布后维护建议

- README 顶部加 GitHub 徽章（Stars / License / 版本）增加可信度
- 有人报杀软误报时，回复"源码开源，可自行编译核对"并给出编译方法
- Issue 模板（可选）：bug 报告模板 / 功能建议模板
- 若希望英文用户看到，可加 `README_en.md` 或在 README 内双语
